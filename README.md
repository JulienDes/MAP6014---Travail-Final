# House Prices — MAP6014

Travail universitaire de deux étudiants, cours **MAP6014**, automne **2026**.
Compétition : [House Prices – Advanced Regression Techniques](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/overview).
Objectif : prédire le prix de vente `SalePrice` des maisons d'Ames, Iowa, par régression supervisée. Les 79 variables explicatives décrivent notamment les surfaces, le quartier, la qualité, l'année de construction et les équipements. `Id` est un identifiant, distinct de la cible et des caractéristiques prédictives.

Le dépôt contient une base de travail : aucun modèle sélectionné, aucune analyse ni transformation implémentée.

## Technologies

Python 3.14, pandas, NumPy, Matplotlib, seaborn, SciPy et scikit-learn. Développement avec VS Code et Jupyter dans un environnement virtuel local.
